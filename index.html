Settings — API key & model

Paste one API key — OpenRouter, OpenAI or Anthropic. The app detects which provider it's from, loads that provider's models, and runs the whole Cabinet — President, Chief of Staff and all 15 secretaries — on the model you pick. Get a key: OpenRouter ↗ (easiest — one key reaches OpenAI, Google, Anthropic, Meta… and adds live web search) · OpenAI ↗ (also unlocks the neural voices) · Anthropic ↗

The key lives only in this browser (localStorage) and is sent only to that provider. Anthropic is called directly via the anthropic-dangerous-direct-browser-access header. Voices use OpenAI's neural TTS when the key is an OpenAI key; otherwise your browser's built-in speech.
